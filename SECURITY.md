## Reporting a Vulnerability

We take the security of our application and users seriously. If you discover a security vulnerability, please report it responsibly:

1. **Do not create a public GitHub issue** for sensitive vulnerabilities.
2. Report the vulnerability via GitHub Security Advisories tab under **Security > Advisories > Report a vulnerability**, or email the maintainer directly.
3. Include detailed steps to reproduce the issue along with a proof-of-concept if possible.

We will review your submission promptly and coordinate a patch and disclosure timeline.
